# 分机器验收模板

将本模板复制到仓库外的私有部署目录，再填写真实机器、账号、应用、会话与回执信息。
公开 Issue 或 PR 只附去除身份信息后的结果。仓库中的自动测试不代表新用户的机器
已经连接或完成飞书授权。

## 自动检查

```sh
npm ci --ignore-scripts
npm run check
npm test
npm run build
python3 -m unittest discover -s deploy -p 'test_*.py'
npm run privacy:check
```

Unix socket 测试需要本地进程能创建临时 socket。连接限制导致的 EPERM 应在允许
本地 socket 的环境重试，不能把跳过测试记为通过。

## 现场验收

| 项目 | 通过标准 | 结果 |
| --- | --- | --- |
| 配置检查 | `--check-config` 成功；白名单与项目根目录均由操作者确认 | 待验证 |
| 只读连接 | `--doctor` 成功；未启动或停止既有 daemon | 待验证 |
| 事件接收 | 消息、卡片回调、菜单事件三种消费者均 ready | 待验证 |
| 目录与会话 | 编号/按钮一致，路径范围正确，状态排序和最近提示词正确 | 待验证 |
| 最新进展 | 真实点击后新卡片出现在聊天底部，可回读且对应当前会话 | 待验证 |
| 测试输入 | 在用户选定的独立测试 session 中发送无副作用提示词 | 待验证 |
| 模型回答 | 该轮完成，飞书回答与实际 session 历史一致 | 待验证 |
| 单次审批/问答 | 仅当前操作者、会话及请求可操作；过期按钮无效 | 待验证 |
| 运行中补充/中断 | 仅在可中断的测试 session 中验证 | 待验证 |
| worker 恢复 | 无待处理审批/指令时仅重启桥接；绑定恢复，daemon 与轮次未重启 | 待验证 |
| 消息队列 | queued / uncertain / unsent 均为 0，或逐项说明原因 | 待验证 |
| SSH 断开 | Mac/SSH 断开后仍可操作 | 待验证 |
| 机器重建 | 单独安排安全窗口，验证平台启动 hook 和状态存储恢复 | 未验证 |

验收提示词示例：`只回复 BRIDGE_OK，不要调用工具。`

记录命令成功、CLI ready、消息发送回执、消息回读、用户真实点击和会话中的模型响应
分别证明了什么，不能相互替代。worker 自动重启通过不代表机器销毁后还能自动恢复。
